# Атмосферные видеоклипы

Художественные короткие клипы с акцентом на настроение и визуальный стиль — необычные операторские приёмы (в т.ч. тепловизионная съёмка), плотная цветокоррекция, монтаж под музыку.

## Процесс
1. Монтаж разнородного материала (обычная + тепловизионная съёмка) в единый ритм
2. Плотная, приглушённая цветокоррекция для атмосферы
3. Синхронизация склеек с музыкальным треком
4. Финальная сборка и экспорт под вертикальный формат
